# EsportSimulator

EsportSimulator is a portfolio game-development project focused on an esports career and management simulation experience. The repository combines a TypeScript frontend with Lua gameplay logic experiments and is intended to be both playable and educational for other game developers.

## Live Demo

- Demo: https://esports-legacy-road-to-worlds.ai.studio

## Technology Overview

- **TypeScript + React + Vite** for the main web application
- **Lua** scripts for gameplay/system experimentation
- **Bun lockfile** present for dependency reproducibility

## Getting Started

### Prerequisites

- Node.js 18+ (or Bun)

### Install dependencies

```bash
bun install
```

Alternative:

```bash
npm install
```

### Run in development

```bash
bun run dev
```

### Type check

```bash
bun run lint
```

### Build for production

```bash
bun run build
```

### Preview the production build

```bash
bun run preview
```
