# 统一生涯：首条可玩流程

当前实现范围是一个可从选手进入老板身份的独立生涯模式。使用虚构的四家俱乐部验证规则，尚未接入真实 2026 LPL 名单、赛事制度、图片或授权内容。旧管理模式和旧独立选手模式保留各自入口和存档。

## 已接入的流程

1. 主菜单选择“电竞人生 · 统一生涯”，先读取云存档。
2. 没有已有统一生涯时，创建角色。可以选择姓名、五个位置、打法和生涯起点。背景与目标目前仅记录在档案。
3. 老将短生涯从 2026 年第 1 天开始，个人积蓄 300000 元，合同周薪 25000 元。个人账户与战队运营账户独立；这些是开发测试参数，不代表真实薪资。
4. 推进原定七天计划，暂停在第 7 天比赛。进入 BO3，每局分对线、资源、团战三个阶段。选手决定自身行动，位置、能力、熟练度、疲劳和选择参与结算。
5. 比赛结束，在“档案”考虑并确认退役。工资按实际履约天数结算；若俱乐部暂时无钱，未付义务留在原合同。
6. 在“战队”购买本世界早已存在的港湾电竞，开发收购价 240000 元。个人向卖方付款；目标运营现金、阵容、合同、资产、债务、赛程与历史保留。
7. 将对应位置的候补调整为首发，修改训练与人员周预算，推进至下一场比赛。老板选择团队战术，主角不会重新变成参赛选手。
8. 退出再读取，检查同一人物、俱乐部、账目、阵容和历史。没有足够个人资金的退役选手可安排解说工作周，收入按实际推进的工作日结算。

“今日／档案／战队／赛事／消息”在两个身份下保持一致。字号提供 100%、125%、150% 切换；当前界面采用可滚动文字面板，尚未制作成长空间插画。

## 状态和代码边界

| 模块 | 责任 |
| --- | --- |
| `scripts/career/World.lua` | 创建唯一世界、稳定人物和俱乐部 ID、合同、账户及引用校验 |
| `Ledger.lua` | 有来源和去向的资金转移；账户余额必须与期初余额和账本一致 |
| `Training.lua` / `Timeline.lua` | 每日活动、可复用周计划、工资、预算、合同到期暂停、赛事时间 |
| `Matches.lua` | BO3 阶段决策、个人贡献、MVP、NPC 对局、进行中比赛恢复 |
| `Actions.lua` | 身份和权限检查、退休、收购、阵容和预算等领域操作 |
| `Runtime.lua` | 在副本上执行、校验、保存确认后发布；拒绝过期页面与重复命令 |
| `SaveStore.lua` | 双快照、版本与校验和、写后读取、失败与不确定结果处理 |
| `Screen.lua` / `ui/Kit.lua` | 读取已确认状态、显示操作后果、提交明确命令 |
| `scripts/LegacySession.lua` / `scripts/main.lua` | 按模式加载与退出，不启动新生涯时加载旧世界 |

新领域模块不引用旧 `CompanyState`。复用的是基础 UI 控件、旧训练影响因素和比赛分阶段流程的思路；旧管理状态与单一战力结算没有直接接入新模式。

预算目前只验证保存、按周扣款和是否启用球队训练：训练预算大于零时执行训练，金额大小尚未改变训练强度；人员预算尚未接入招聘或人员效果。它们不代表完整的俱乐部经营系统。

## 保存约束

- 正常游戏使用 `clientCloud`，键为 `unified_career_v1_slot1_a` 和 `unified_career_v1_slot1_b`，不会访问两个旧存档文件。
- 文档指出 WASM 本地文件在刷新后丢失，因此云端故障不会静默降级到本地文件并声称已经持久保存。
- 操作只有在快照写入并读取验证后才显示成功；过程中锁住新的世界操作。
- 写入结果不确定时，保留已确认内存状态并锁住操作，直到重新读取能确认结果。不以超时直接认定回滚。
- 对引擎文档明确规定的限流反馈（数字 `-429` 且原因严格为 `send failed`），允许在未保存时稍后重试并保留原状态；若读回本次完整快照则确认成功。版本与世界冲突、未知错误和超时的保护仍保留。
- 当前只支持一个受保护的新生涯槽，不覆盖已有世界；损坏或不支持的版本不会自动变成新游戏。
- 双快照不是跨设备事务。当前按一个账号只有一个活跃游玩会话设计；引擎公开接口没有提供可用于这里的跨设备 CAS 保证。

## 本地验证

命令：`python tests/run_career.py`。运行器使用本机已安装的 `lupa.lua54` 和真实 JSON 编解码，测试文件与模拟云都在内存中，不访问玩家数据。

最近一次完整结果：5 个测试集、615 项断言通过（2026-10-10）。

- `career_flow.lua`：实际规则与 JSON 存储的选手—老板完整流程、读取、重复提交、资金不足、保存失败、退休后的工作收入。
- `career_match.lua`：五位置、个人选择的因果影响、老板战术、阶段恢复、MVP 与赛果校验、NPC 比赛只结算一次。
- `career_review.lua`：损坏世界拒绝加载、工作权限、欠薪及合同到期准确结算。
- `career_save.lua`：双快照、真实 JSON 往返、部分写入、版本冲突、写入不确定、延迟云回调，以及限流拒绝后的恢复与重试。
- `career_ui.lua`：实际入口、页面与命令代码，模拟控件和同步／异步云回调，通过点击完成主流程与新旧模式往返。

这些测试不证明引擎真实渲染或线上云服务行为。
